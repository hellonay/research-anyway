# 접근 권한 (Access Control)

## Decisions

- 이 앱은 로그인·계정 시스템을 두지 않는다. 여행 페이지 URL(공유 링크)을 아는 사람은 누구나 전체 내용을 열람하고, Day와 일정 항목을 추가·삭제할 수 있다.

## Boundaries

- 뷰어와 편집자 구분, 초대 코드, 비밀번호 보호 등 접근 제한 기능은 이 결정의 범위 밖이다.
- 여러 여행(트립)을 다루게 되어도 트립별 접근 제한을 두지 않는 것이 기본값이다.

## Why

친구들끼리 여행 준비 정보를 빠르게 공유하는 것이 목적이고, 인증 시스템을 구현하면 "한 번에 구현하고 실제 동작으로 검증"할 수 있는 범위를 벗어난다. 신뢰할 수 있는 소규모 그룹이 링크를 공유하는 사용 맥락이므로 오남용 위험을 감수하기로 했다.

## Reconsider when

- 여행 페이지가 불특정 다수에게 공개되어 악의적 삭제가 발생하거나, 여러 그룹이 같은 배포를 공유해 데이터가 섞이는 문제가 생기면 재검토한다.

## Still-rejected alternatives

- 로그인 기반 멤버 인증 — 구현 범위가 커져 보류; 여러 그룹이 동시에 쓰는 서비스로 확장할 때 재검토.
